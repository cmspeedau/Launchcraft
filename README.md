# Launchcraft

A custom Minecraft launcher.

## Roadmap

The project roadmap is tracked in [Issue #1](https://github.com/cmspeedau/Launchcraft/issues/1). It starts with choosing the initial platform and app framework, then covers the launcher UI and profiles, Microsoft authentication, Minecraft installation and launch, and release readiness.

The scope is intentionally based on the current project goal. Platform support and technical choices should be confirmed before implementation begins.
